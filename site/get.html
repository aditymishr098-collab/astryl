InstallInstall कैसे करें

  1. Download the APK from the button above on your phone.ऊपर के button से अपने फ़ोन में APK download करें।
  2. Open it. If Android asks, allow your browser (or file manager) to install apps.उसे खोलें। Android पूछे तो अपने browser (या file manager) को apps install करने दें।
  3. Tap Install. Astryl updates itself later: Settings → Check for updates.Install दबाएँ। आगे Astryl खुद update होता है: Settings → Check for updates।

Coming from Heliora (before version 1.17.5)?Heliora (version 1.17.5 से पहले) से आ रहे हैं?

Astryl 1.17.5 has a new app id, so it installs next to the old Heliora instead of replacing it. Your data moves in a minute:Astryl 1.17.5 का app id नया है, इसलिए यह पुराने Heliora की जगह नहीं लेता, उसके बग़ल में install होता है। आपका data एक मिनट में आ जाता है:

  1. In the old Heliora: Settings → Backup → Save a backup.पुराने Heliora में: Settings → Backup → Save a backup।
  2. In Astryl: Settings → Backup → Restore a backup, pick that file.Astryl में: Settings → Backup → Restore a backup, वही file चुनें।
  3. Uninstall the old Heliora.पुराना Heliora uninstall कर दें।
