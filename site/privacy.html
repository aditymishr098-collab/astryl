5. Crash reports (on by default, you can switch them off)5. Crash reports (डिफ़ॉल्ट रूप से चालू, आप बंद कर सकते हैं)

  • If the app crashes, it sends one small report to the Astryl server: the error text, the technical trace of where it happened, the app version, the Android version string and the app language. It contains no name, no account, no device id, no IP address (the server keeps none in readable form) and no location.App crash हो तो वह Astryl server को एक छोटा report भेजता है: error का text, कहाँ हुआ उसका technical trace, app version, Android version string और app की भाषा। उसमें कोई नाम, खाता, device id, IP address (server उसे पढ़ने लायक़ रूप में नहीं रखता) या location नहीं होती।
  • It is used only to find and fix bugs, and is kept for 90 days. If the phone is offline, the report waits on the phone and is sent later.इसका इस्तेमाल सिर्फ़ bugs ढूँढने और ठीक करने के लिए होता है, और यह 90 दिन रखा जाता है। फ़ोन offline हो तो report फ़ोन पर रुका रहता है और बाद में भेजा जाता है।
  • Turn it off in the You tab → Send crash reports. Nothing is then kept or sent, and reports still waiting on the phone are not sent.इसे You tab → Crash reports भेजें में बंद करें। तब कुछ रखा या भेजा नहीं जाता, और फ़ोन पर रुके reports भी नहीं भेजे जाते।

6. Where the data is kept and who handles it6. Data कहाँ रखा जाता है और कौन सँभालता है

Account data is stored with Supabase (database and login service), on servers in Singapore. The app and this website reach it only through one function that checks who is asking; the tables themselves cannot be read from outside. To limit abuse, a hashed (not readable) key and a counter are kept for up to 2 days; no IP address is stored in readable form. This website is a plain static site, and downloads and the update check use GitHub, which follows its own privacy statement. Visitors and placesVisitors और जगहें

To see how many different people visit, the Astryl server makes a one-way code from your IP address, the day and a secret that only the server knows, and adds that code to the list for the day. The IP address itself is not saved. The code cannot be turned back into an address, and it is different on every day, so a person cannot be followed from one day to the next. The codes are deleted after 90 days. This is not done if your browser sends “Do Not Track” or “Global Privacy Control”.यह देखने के लिए कि कितने अलग लोग आते हैं, Astryl server आपके IP address, दिन और एक ऐसे secret से, जो सिर्फ़ server जानता है, एक एकतरफ़ा code बनाता है और उस दिन की सूची में जोड़ देता है। IP address ख़ुद सेव नहीं होता। Code को वापस address में नहीं बदला जा सकता और वह हर दिन अलग होता है, इसलिए किसी व्यक्ति का एक दिन से दूसरे दिन पीछा नहीं हो सकता। Codes 90 दिन बाद मिटा दिए जाते हैं। अगर आपका browser “Do Not Track” या “Global Privacy Control” भेजता है तो यह नहीं होता।

The place question is optional. If you press “Share”, your browser asks for permission; the point is rounded to about 10 km and added to a count for the day. It carries no code, no account and no IP address, so it cannot be tied to you. If you say no, nothing is sent. Your answer is kept only in your browser.जगह वाला सवाल वैकल्पिक है। “बताएँ” दबाने पर आपका browser अनुमति माँगता है; बिंदु को लगभग 10 km तक गोल करके उस दिन की गिनती में जोड़ा जाता है। उसके साथ कोई code, खाता या IP address नहीं होता, इसलिए वह आपसे जोड़ा नहीं जा सकता। आप मना करें तो कुछ नहीं भेजा जाता। आपका जवाब सिर्फ़ आपके browser में रहता है।
