PrivacyPrivacy

Short version: Astryl has no ads, no analytics and no account. What you do in the app stays on your phone.छोटे में: Astryl में विज्ञापन, analytics और account नहीं हैं। आप app में जो करते हैं वह आपके फ़ोन में ही रहता है।

The appApp

  • Planet facts, the Moon, planet positions, eclipses and the star map are worked out on your phone. No internet is needed.ग्रहों के तथ्य, चाँद, ग्रहों की स्थिति, ग्रहण और star map आपके फ़ोन पर ही निकाले जाते हैं। Internet ज़रूरी नहीं।
  • Your city, birth date, favourites, quiz scores and settings are saved only on the phone. The Backup file is created by you and goes where you send it.आपका शहर, जन्मतिथि, favourites, quiz scores और settings सिर्फ़ फ़ोन में save होते हैं। Backup file आप बनाते हैं और वह वहीं जाती है जहाँ आप भेजें।
  • Update check: the app asks GitHub for the newest release (once a day if you leave it on). GitHub sees your IP address like for any web request. You can turn this off.Update check: app GitHub से सबसे नया release पूछता है (चालू रखने पर दिन में एक बार)। जैसे हर web request में होता है, GitHub आपका IP address देख सकता है। इसे बंद किया जा सकता है।
  • Online features are off until you turn them on. Then the app downloads orbit data (for the space station, Tiangong and Hubble), the rocket launch list and space news from public services. No account, and nothing about you is uploaded.Online features आप चालू करें तभी चलते हैं। तब app public services से orbit data (space station, Tiangong, Hubble के लिए), rocket launch की list और space news download करता है। कोई account नहीं, और आपके बारे में कुछ upload नहीं होता।
  • Permissions: notifications (for reminders you ask for), the compass sensor (planet finder) and, in the app, installing updates you approve.Permissions: notifications (आपके माँगे reminders के लिए), compass sensor (ग्रह खोजक) और आपकी मंज़ूरी से updates install करना।

This websiteयह website

  • No cookies, no analytics, no ads, no third-party scripts or fonts. Everything is calculated in your browser.कोई cookies, analytics, विज्ञापन, बाहरी scripts या fonts नहीं। सब कुछ आपके browser में calculate होता है।
  • Your browser remembers your language, theme and best quiz scores on your own device (local storage). It is never sent to us.आपका browser भाषा, theme और quiz के best scores आपके अपने device में याद रखता है (local storage)। यह हमें कभी नहीं भेजा जाता।
  • The site is hosted on GitHub Pages, which may keep normal server logs under GitHub's own privacy statement. The download button loads the newest release from the GitHub API.Site GitHub Pages पर है, जो अपनी privacy policy के हिसाब से सामान्य server logs रख सकता है। Download button GitHub API से सबसे नया release लेता है।
